# FermatOrbits

Программа проверки результатов статьи

> Р. Р. Шарипов, Р. Ф. Гибадуллин. **Орбиты и стабилизаторы группы симметрий решений сравнения Ферма по простому модулю.**

Для множества Ω<sub>n,p</sub> = {(x, y, z) ∈ (𝔽<sub>p</sub><sup>\*</sup>)³ : xⁿ + yⁿ ≡ zⁿ (mod p)} и его группы симметрий программа

1. **orbits** — строит проективные точки Ω̄<sub>n,p</sub>, вычисляет орбиты и стабилизаторы группы
   K<sub>n,p</sub> = (μ<sub>n</sub> × μ<sub>n</sub>) ⋊ S₃ для всех нечётных n ≤ 15 и простых p ≤ 1500 (p > n)
   и сравнивает их с теоремой 1 (длины орбит, порядки стабилизаторов, число орбит
   k = N/(6d²) + ε/2 + 2δ/3) и следствием 2 (критерий транзитивности);
2. **gl3** — полным перебором находит все матрицы из GL₃(𝔽<sub>p</sub>), сохраняющие Ω<sub>3,p</sub>,
   при p = 5, 11, 17, 19 (метод образов базиса: выбираются три линейно независимых вектора
   из Ω, перебираются все |Ω|³ троек их образов).

## Запуск

**Windows, одним файлом.** Запустите `FermatOrbits.cmd`. Он находит установленный
[.NET SDK](https://dotnet.microsoft.com/download) (8 и новее), собирает программу в Release
и выполняет полный протокол; без SDK использует компилятор csc.exe из .NET Framework 4.x.
Результат пишется на экран и в файл `FermatOrbits_protocol.txt`.

**Любая ОС, .NET SDK:**

```
dotnet run -c Release                    # полный протокол
dotnet run -c Release -- orbits 15 1500  # только орбиты, границы n и p задаются
dotnet run -c Release -- gl3 19          # только поиск в GL_3 для указанных p
dotnet run -c Release -- gl3 19 -1       # то же в один поток
```

**Python 3** (независимая реализация тех же проверок, только стандартная библиотека;
NumPy ускоряет режим gl3):

```
python3 python/orbits_check.py orbits 15 1500
python3 python/orbits_check.py gl3 19
```

## Соглашения

Точки Ω̄<sub>n,p</sub> записываются в координатах (x : y : w), w = −z, с нормировкой x = 1;
элемент (σ, (a, b, 1)) группы K<sub>n,p</sub> действует матрицей diag(a, b, 1)·P<sub>σ</sub>,
где P<sub>σ</sub>(x₁, x₂, x₃) = (x<sub>σ(1)</sub>, x<sub>σ(2)</sub>, x<sub>σ(3)</sub>).
Признаки: ε = 1, если −2 — вычет n-й степени по модулю p; δ = 1, если p ≡ 1 (mod 3)
и примитивный кубический корень из единицы — вычет n-й степени.
